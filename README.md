# FIREシミュレーター

働き方・結婚・子ども・FIRE後の暮らしを入れると、何千通りもの運用結果を試算して「決めた年齢でFIREしても資金が最後までもつ確率」を出すアプリです。金額の単位はすべて **万円** で、入力は今の価値です。

## すぐに使う（インストール不要）

**▶ https://shisakulab.github.io/fire-sim/**

使い方と試算の例は、note の解説記事で紹介しています：[平均的な30歳・独身は何歳でFIREできるか、1万通りの未来で試算](https://note.com/shisaku_lab/n/n7f778b3c5c2b)

ブラウザで開くだけで使えます。入力した設定は **お使いのブラウザの中にだけ** 保存され、外部には送信されません（計算もすべてブラウザの中で行います）。

初期値と3つのプリセット（平均的な30歳・独身で50歳FIRE／サイドFIRE／結婚・子ども2人）は、公的統計の平均値でつくった説明用の **架空の人物** です（出典は画面下の「計算に使った制度・数字の出典」）。ご自身の数字に書き換えて使ってください。

> **ご注意**：このアプリの結果は、入力した仮定に基づく試算で、将来を保証するものではありません。特定の金融商品の売買をすすめるもの（投資助言）でもありません。年金・税・教育費・社会保険の制度は改正で変わることがあります。大きな判断の前には、FPなどの専門家に相談してください。

## できること

- FIREする年齢とFIRE後の生活費から、資金が寿命までもつ確率を出す
- 資産残高の見通し、毎年の支出と収入、年ごとの収支表
- 「FIRE年齢 × 生活費」のマップと、目標の確率を超える最短のFIRE年齢
- 条件を入れたURLを作る「共有リンクをコピー」、印刷・PDF出力

## 自分のパソコンで動かす（設定をファイルに保存したい場合）

以下は、Python を使って自分のパソコンの中だけで動かし、画面で変えた設定を `config.json` に保存する使い方です。

| ファイル | 役割 |
|---|---|
| `start.bat` | ダブルクリックでアプリを起動する |
| `server.py` | アプリをこのパソコンの中だけで動かし、設定を `config.json` に保存するプログラム |
| `FIREシミュレーター.html` | アプリの本体（画面と計算） |
| `config.json` | 画面で設定した値（自動で作られ、更新される。**Git には含めない**） |
| `config.example.json` | 見本の設定。**アプリの初期値とプリセットはここから読み込む**（架空の人物の値） |
| `index.html` | 公開ページの入口（本体へ移動するだけ） |

必要なもの：Windows、**Python 3.8 以上**（https://www.python.org/downloads/ ・インストール時に「Add python.exe to PATH」にチェック）、ブラウザ（Edge または Chrome）。

1. `start.bat` をダブルクリックします。
2. 黒いウィンドウが開き、少しするとブラウザでアプリが開きます（開かない場合は http://127.0.0.1:8766/ ）。
3. 画面左の条件を変えると、結果がすぐ計算し直され、`config.json` に保存されます。

終了するときは、ブラウザのタブを閉じ、黒いウィンドウも閉じます（または `Ctrl + C`）。

```
python server.py --local
```

| オプション | 意味 |
|---|---|
| `--local` | `config.json` を読み込み、画面の変更を `config.json` に保存する（`start.bat` はこれを付けて起動） |
| `--port 8767` | ポート番号を変える（既定: 8766） |
| `--no-browser` | ブラウザを自動で開かない |

`--local` を付けずに `python server.py` だけで起動すると、見本の `config.example.json` で開き、画面で変えても何も保存しません。

## 設定キー（`config.example.json` の `params`）

初期値は、公的統計の平均値でつくった架空の人物（30歳・会社員・独身）の値です。出典は画面下の「計算に使った制度・数字の出典」にあります。

| キー | 意味 | 初期値 |
|---|---|---|
| `age` / `life` | 現在の年齢 / この年齢まで資金を用意 | 30 / 85 |
| `assets` / `nisaNow` / `cash` | 投資している資産 / うちNISA分 / 投資とは別の現金（万円） | 154 / 154 / 237 |
| `takeHome` / `gross` | 今の手取り年収 / 額面年収（万円） | 390 / 464 |
| `living` | 今の生活費（月額・万円） | 17.9 |
| `wageGrowth` | 手取りの伸び（%/年） | 1.5 |
| `careerStart` | 厚生年金に入った年齢 | 22 |
| `stepAge` / `stepNet` / `stepGross` | 昇給の段階（◯歳から手取り◯万円・額面◯万円）。0は未使用 | 35, 40, 50 / 402, 433, 468 / 513, 554, 598 |
| `married` | 結婚するか（`false` なら、ずっと今の生活費で計算し、結婚の年齢・費用・生活費は使わない） | false |
| `marryAge` / `wedding` / `livingMarried` | 結婚する年齢 / 費用 / 結婚後の生活費（`married` が `true` のときだけ使う） | 31 / 0 / 17.9 |
| `kids` / `birth` | 子どもの人数 / 産む年齢 | 0 / 33, 35 |
| `path` | 子どもの進路（0〜6） | 2, 2 |
| `eduShare` | 教育費の自分の負担割合（%） | 50 |
| `kidLiving` / `uniAway` / `allowance` | 子どもの生活費（月額）/ 大学の仕送り（年額）/ 児童手当を入れるか | 2 / 0 / true |
| `leaveYears` / `leaveRate` / `shortYears` / `shortRate` | 育休の年数・手取り割合 / 時短の年数・手取り割合 | 1 / 80 / 2 / 80 |
| `fireAge` / `fireLiving` | FIREする年齢 / FIRE後の生活費（月額） | 50 / 17.9 |
| `severance` | FIRE時の退職金（手取り・万円） | 0 |
| `side` / `sideUntil` | FIRE後の収入（月額）/ 何歳まで | 0 / 60 |
| `socialPre60` / `socialPost60` | 社会保険料（年額）FIRE後〜60歳 / 60歳から | 33.7 / 17.2 |
| `target` | 目標とする確率（%） | 80 |
| `pensionStart` / `netRate` / `slide` | 年金の受け取り開始年齢 / 手取り率（%）/ 目減り（%/年） | 65 / 90 / 0.2 |
| `ndxShare` | 株のうちNASDAQ100の割合（%）。残りは全世界株 | 0 |
| `cashYears` / `crashRule` / `crashDD` | FIRE後に現金で持つ年数 / 暴落時ルール / 暴落とみなす下落率（%） | 2 / true / 20 |
| `inflation` | インフレ率（%/年） | 2 |
| `acwiRet` / `acwiVol` | 全世界株の期待リターン / リスク（%） | 7.6 / 20.4 |
| `ndxRet` / `ndxVol` | NASDAQ100の期待リターン / リスク（%） | 7 / 26 |
| `cashRet` | 現金の金利（%） | 0.3 |
